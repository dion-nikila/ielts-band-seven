# Band Seven — IELTS Prep Lab

A browser-based IELTS Academic preparation app with a seven-day study plan, timed writing, speaking prompts, original reading and language drills, a mistake notebook, mock-result tracking and a researched video library.

All study progress stays in the browser. Use Settings & sources to export or restore backups. No backend or API keys are required.

The app uses public IELTS criteria for guidance. Practice items and self-assessment do not establish an official IELTS band.
